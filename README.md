# Mario Kart PSP

PSP için fan yapımı Mario Kart tarzı homebrew proje.

## GitHub Actions ile EBOOT.PBP

1. Bu klasörün içeriğini GitHub repository'ne yükle.
2. `.github/workflows/build.yml` dosyasının doğru yerde olduğundan emin ol.
3. GitHub'da **Actions** sekmesine gir.
4. **Build Mario Kart PSP** workflow'unu aç.
5. **Run workflow** seçeneğine bas.
6. Build tamamlanınca **Artifacts** bölümünden `MarioKartPSP-EBOOT-PBP` dosyasını indir.

PSP'ye kopyalama:

```text
PSP/GAME/MARIOKART/EBOOT.PBP
```
